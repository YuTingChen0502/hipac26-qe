# e001-npool-screen

Status: historical execution complete.

With G4X, 14 MPI ranks, 14 GPUs, two nodes, seven actual k-points
and OMP=12 fixed, this experiment compared nk=1, nk=2 and nk=7.

Historical job 200732 established nk=7 as the tested winner for this
exact A1 resource shape. This is case-level evidence, not a universal
Type A rule.
